Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) competition on make.fun.

The program writes a single sentence to `/output/entry.txt`: every time the inbox dings for the twelfth time before lunch, the Notification Tamer answers each ping in the owner's voice and schedules a meeting with itself to discuss them all — an absurd little machine that "fixes" notification overload by becoming the meeting it was trying to avoid.
